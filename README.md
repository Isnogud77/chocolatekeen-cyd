# chocolatekeen-cyd

Commander Keen 1 ("Marooned on Mars") on a ~$15 ESP32 "Cheap Yellow Display"
board, built into a small arcade cabinet with a joystick and two buttons.

This is a port of [Chocolate Keen](https://github.com/jamesfmackenzie/chocolatekeen),
a faithful C reimplementation of the Vorticons engine. The game logic is
upstream's, nearly untouched; this repo adds a new display, sound, input and
storage layer that fits into an ESP32 without PSRAM.

- Full game: title, menu, world map, all 16 levels, ending
- Landscape or portrait (upright, Galagino-style) cabinet — chosen at build time
- PC-speaker sound through the CYD's speaker output
- Autosave and high scores in the ESP32's flash
- ~24 fps, ~37 KB of the ESP32's RAM left free

## Hardware

The easiest way to get all of it is the
**[CYD Galagino Arcade Cabinet](https://www.hackster.io/dynamight/cyd-galagino-arcade-cabinet-369ce9)**
build on Hackster: it covers the parts, the 3D-printed cabinet and the control
board. Build that, then flash this firmware instead of Galagino —
use the `cyd_portrait` env for its upright cabinet.

| Part | Notes |
|---|---|
| ESP32-2432S028R ("CYD", tested: the CYD2USB variant with USB-C + Micro-USB) | ESP32-WROOM-32, 4 MB flash, no PSRAM, 2.8" 320×240 ST7789 |
| MCP23017 I2C port expander | on the CYD's CN1 connector: SDA GPIO 22, SCL GPIO 27, address 0x20 |
| 4-way digital joystick + 2 buttons | to MCP23017 GPA0–GPA5, active low; optional Start/Menu on GPB0/GPB1 |
| Small speaker | on the CYD speaker connector (DAC, GPIO 26) |

Wiring, the full pin map and what every control does: **[docs/controls.md](docs/controls.md)**.

## Build and flash

You need [PlatformIO](https://platformio.org/) (CLI or the VS Code extension).

```sh
pio run -e cyd -t upload            # landscape cabinet
pio run -e cyd_portrait -t upload   # upright (portrait) cabinet
```

If the board is on a different serial port, add `--upload-port /dev/...`.
The serial monitor runs at 115200 baud and logs fps and free heap.

To wipe saves and high scores: `pio run -e cyd -t erase`, then upload again.

### Run it on a computer

The same code builds for macOS/Linux with SDL2 as a "fake CYD" — handy for
development without the board.

```sh
brew install sdl2                   # or your distro's libsdl2-dev
pio run -e host && .pio/build/host/program
```

Arrows = joystick, Z = button 1, X = button 2, Esc = quit. `host_portrait`
shows the portrait layout. Unit tests: `pio test -e test`.

## Controls (short)

| | In a level / on the map | In menus and text screens |
|---|---|---|
| Joystick | move | select, page |
| Button 1 | jump | confirm / yes |
| Button 2 | pogo | back / no |
| Both buttons | fire | — |
| Hold button 2 for 1 s | quit to title? | — |
| Hold down for 1 s (in a level) | status screen | — |

High-score names are entered with a letter picker (up/down = letter,
right = next, button 1 = done). The game autosaves whenever Keen is back on
the world map; **Continue Game** resumes. Details: [docs/controls.md](docs/controls.md).

## How it works

- `upstream/` — a vendored subset of Chocolate Keen. Every local change is
  marked `// ESP32-PORT: <reason>`.
- `port/` — the new platform layer:
  - `render.c` replaces upstream's emulated EGA memory (393 KB) with a
    336×224 8-bit playfield that is redrawn every frame; `screen_layout.c`
    turns it into a landscape picture or a portrait window that follows Keen.
  - `esp32/` drives the ST7789 over SPI DMA, the MCP23017 over I2C, the
    speaker (DAC square wave on a hardware timer) and NVS storage; `host/` is
    the SDL2 equivalent.
  - `input_map.c` turns buttons into the DOS scancodes upstream expects,
    depending on context (play vs. menu, long presses, letter picker).
  - `pcspeaker.c` plays Keen's PC-speaker tone lists; `save_store.c` keeps
    upstream's save and score files in a small key-value store.
- `assets/` — Keen 1 graphics, levels and the unpacked EXE as `const` arrays
  in flash (generated by `tools/assetdump` from `data/KEEN1`).
- `docs/superpowers/` — the design specs and implementation plans the port was
  built from, plus open follow-ups.

## Known limitations

- Only Episode 1 is built in.
- No save-slot choice, no key remapping, no demos (not needed on a cabinet).
- The CYD's speaker amplifier picks up a faint background noise from the board
  itself; the volume is fixed in code (`kSpeakerAmplitude`).
