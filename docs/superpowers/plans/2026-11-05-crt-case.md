# CRT All-in-One Case Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A parametric SolidCraft model and printable STLs of a 90s beige all-in-one (CRT + keyboard) bartop case for the CYD, control PCB, speaker, USB-C socket, slide switch and a 3 mm LED.

**Architecture:** One side profile extruded to `W`, rounded and shelled, then split into flat panels (same method as `cad/keen-cabinet-landscape.sc`). Panels sit in 1 mm grooves in the 3 mm side panels with 2 mm pegs and get glued; only the Back hatch is screwed. Dark detail parts are separate bodies.

**Tech Stack:** SolidCraft via the `mcp__solidcraft__*` tools (read `skill_reference {"skill":"solidcraft-modeling"}` first). Units mm, Z up, Y = depth (front at Y 0, back at +Y), X = width centred on 0. The landscape cabinet uses the same axes; open it read-only for reference only, never save it.

**Spec:** `docs/superpowers/specs/2026-11-05-crt-case-design.md`

## Global Constraints

- Design file `cad/keen-crt-landscape.sc`; STLs in `cad/print-crt/`, one per body, named after the body
- `cad/keen-cabinet-landscape.sc` and `cad/print/` are not modified
- Every size is a named user parameter with a comment (spec table "Shape and main parameters" plus the fit values); no bare numbers in features that a parameter covers
- Fits: groove = panel thickness + 0.3, groove depth 1; pegs 2.0 into 2.4 blind holes; cap hole = cap + 0.6; fake key gap 0.4, keys 1.5 proud; press fits 0.2; LED hole 3.1
- Hardware numbers copied from the landscape cabinet: `cyd_dx` 78, `cyd_dy` 42, `cyd_off` 2.85, `cyd_so` 4, `cyd_so_d` 6, `m3_pilot` 2.5, `board_so` 5.5, `so_d` 4.5, `m2_pilot` 1.8, standoffs at x = +-22.5 and y = 8.5 / 6.5 from the control PCB origin, control PCB 50 x 22, `spk_d` 35, `grille_d` 2.5, `usb_w` x `usb_h` 11 x 6, `cap_d` 9, `cap_flange_d` 11.4, `cap_fit` 3.1, `knob_stem_d` 5.5, `joy_hole_d` = `knob_stem_d` + 3.9
- All shell panels must print flat without supports
- Every stage ends with `measure` (volume, bbox) compared against the numbers in the task; `ok: true` alone is not a pass
- Commit `cad/keen-crt-landscape.sc` (and later `cad/print-crt/`) after each task; do not stage other untracked files under `cad/`

## Review Focus

1. Parameter changes (`W`, `face_ang`, `deck_ang`, `H_front`) must not break grooves, pegs or the split: the check in Task 2 Step 4 covers this with `check_parameters`.
2. The CYD stack (PCB + 4 mm module + components, ~15 mm behind the face) must clear the Top and the leaning Back: Task 7 interference check.
3. The control PCB under the deck must clear the Bottom (needs >= 3 mm under the PCB for solder joints): Task 4 Step 3 asserts it.
4. The Back hatch must go in and out: the hook rotates under the Bottom lip, so the lip must not overlap the hatch along its swing. Task 5 Step 4 checks the clearance at 5 deg of swing.
5. Fake keys must not touch the real caps when they are pressed or tilted: 0.4 gap plus cap + 0.6 hole, Task 6 Step 2.

### Task 1: Design file, parameters, outer shell

**Files:**
- Create: `cad/keen-crt-landscape.sc`

**Interfaces:**
- Produces: user parameters from the spec table (`W` 104, `wall` 2.4, `side_t` 3, `H_front` 16, `deck_d` 48, `deck_ang` 8 deg, `step_h` 3, `chin_h` 14, `face_len` 90, `face_ang` 10 deg, `top_d` 30, `back_ang` 12 deg, `r_top` 10, `win_w` 60, `win_h` 47, `win_r` 4, `bezel` 2.3) plus derived ones: `z_deck = H_front + deck_d*tan(deck_ang)`, `z_face = z_deck + step_h`, `y_top = deck_d + face_len*sin(face_ang)`, `z_top = z_face + face_len*cos(face_ang)`, `D = y_top + top_d + z_top*tan(back_ang)`. One body `Shell`.

- [ ] **Step 1:** `new_design`, add all parameters above, save as `cad/keen-crt-landscape.sc`.
- [ ] **Step 2:** Sketch `SideProfile` on the YZ plane, dimensioned only by parameters (dof 0): (0,0) → (0,`H_front`) → (`deck_d`,`z_deck`) → (`deck_d`,`z_face`) → (`y_top`,`z_top`) → (`y_top+top_d`,`z_top`) → (`D`,0) → close. Extrude symmetric to `W` → `Cabinet`.
- [ ] **Step 3:** Fillet the top-front edge (face/top) with `r_top`, the top-back edge with 4, the front-bottom edge with 2, the outer side edges with 1.5. Shell inward by `wall`, no open faces → `Shell`.
- [ ] **Step 4: Verify.** `measure`: bbox X -52..52, Y 0..~118.2, Z 0..~114.0 (z_top = 16 + 6.75 + 3 + 88.63 = 114.38 before fillets). One body. Screenshot iso + right.
- [ ] **Step 5:** Save, `git add cad/keen-crt-landscape.sc`, commit `feat(cad): CRT case outer shell`.

### Task 2: Split into panels, grooves, pegs, half-laps

**Files:** Modify `cad/keen-crt-landscape.sc`

**Interfaces:**
- Consumes: `Shell`
- Produces: bodies `SideLeft`, `SideRight`, `Bottom`, `Front`, `Deck`, `Bezel`, `Top`, `Back`. Parameters `groove_d` 1, `groove_clr` 0.3, `peg_d` 2.0, `peg_hole_d` 2.4, `peg_len` 2.

- [ ] **Step 1:** Split the side slabs at x = +-(`W`/2 - `side_t`): `SideLeft`, `SideRight` are 3 mm thick, the rest is panels. Split the middle part on the profile's corner planes into the six panels. `Bezel` includes the 3 mm step (its lower edge runs down to the deck surface).
- [ ] **Step 2:** Grooves: every panel is extended `groove_d - 0.1` into each side; the side gets a groove of panel thickness + `groove_clr`, `groove_d` deep (cut with the panel's footprint offset by `groove_clr/2`). The groove stops `wall` short of the side's outer edge so it is not visible from outside.
- [ ] **Step 3:** Pegs: two `peg_d` x `peg_len` pegs on each panel end (at 25 % and 75 % of the panel length), matching `peg_hole_d` holes `peg_len + 0.3` deep in the groove floor. Half-lap notches (half `wall` each) on the Front/Deck, Deck/Bezel and Bezel/Top edges. `Back` gets **no** grooves on its rear edge (it must drop in from behind): its side edges sit in open-backed rebates, no pegs.
- [ ] **Step 4: Verify.** 8 bodies. Pairwise interference between all bodies = 0 volume (gap only). `check_parameters {"set":{"W":110,"face_ang":"14 deg","H_front":"20 mm"}}` rebuilds without errors and still gives 8 bodies.
- [ ] **Step 5:** Save, commit `feat(cad): CRT case panels with grooves and pegs`.

### Task 6: Detail parts

**Files:** Modify `cad/keen-crt-landscape.sc`

**Interfaces:**
- Consumes: Deck pocket and holes (Task 4), Bezel badge recess and floppy opening (Task 3)
- Produces: bodies `KeyField`, `KeyCap1`, `KeyCap2`, `JoyCap`, `FloppyInsert`, `Badge`. Parameters `key_u` 9 (key pitch), `key_gap` 0.4, `key_h` 1.5

- [ ] **Step 1:** `KeyField`: plate = pocket - 0.2 per side, `kf_t` thick. Raised keys on a `key_u` grid, `key_u - key_gap` square, `key_h` tall: 4 rows behind the controls, one row beside them; one wide "space bar" key is fine. Cut-outs around the real controls: `cap_d + 0.6 + 2*key_gap` square for the buttons, `knob_d + 2` square for the joystick; no fake key in any cut-out.
- [ ] **Step 2:** `KeyCap1/2`: square 9 x 9, top 1 mm above the fake keys' top, rounded 1 mm, `cap_fit` socket, `cap_flange_d` flange under the deck. `JoyCap`: square 12 x 12 x 3 low cap on a `knob_stem_d` stem. **Verify:** gap between each cap and the nearest fake key >= 0.4; the caps clear their holes at 3 deg tilt.
- [ ] **Step 3:** `FloppyInsert`: `floppy_w` x `floppy_h` face with a 1 mm deep, 22 x 1.5 slot and a 4 x 2 eject bump, 3 mm deep plug. `Badge`: `badge_w - 0.2` x `badge_h - 0.2` x `badge_dp`, raised "KEEN" 0.6 mm (if text is not available, raised block letters from sketches).
- [ ] **Step 4: Verify.** Interference of each detail part with its host = 0; 14 bodies in total. Screenshot iso.
- [ ] **Step 5:** Save, commit `feat(cad): CRT key field, caps, floppy insert, badge`.
